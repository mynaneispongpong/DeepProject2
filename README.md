# AI 모델 재현 및 성능 비교 과제





## 1. 코드 설명
본 과제는 sEMG(표면 근전도) 신호를 활용하여 팔꿈치 각도(30°,60°) 및 다양한 손동작을 분류하는 AI모델을 구현하고 성능을 비교합니다.

### 사용한 데이터 및 전처리 방법
* 데이터 : sEMG-Hand-Gesture-Elbow-Angle-Dataest 을 사용하며, 데이터는 CSV 파일 형태로 구성되어 있습니다.
* 채널 및 신호 : 각 데이터는 5개의 채널(ECR, ED, FDS, Biceps, Triceps)로 수집되었습니다.
* 전처리 : 신호의 전체 구간 중 동작이 실제로 발생하는 구간을 정의하여 데이터를 분리했습니다. 기준은 전체 샘플의 20%~60% 구간 또는 2.0초 ~ 3.0초 구간을 동작 구간으로 설정하여 특징을 추출했습니다.

### 사용한 AI/ML 모델
* scikit-learn 및 xgboost 라이브러리를 활용하여 3가지 모델을 구성했습니다.

### 학습 및 테스트 방법
* 동작 구간에서 추출한 통계적 특징을 입력 데이터로 사용하였으며, Train/Test 셋을 80:20으로 분할하여 학습 및 평가를 진행했습니다.

| `main_4_4.py` | 특정 동작에 대해 30°와 60° 팔꿈치 각도의 5채널 신호 비교 플롯 생성 |

## 2. 모델 성능 비교
동일한 전처리 과정을 거친 sEMG 데이터를 바탕으로 3개의 분류 모델을 학습하고 성능을 비교했습니다.

| Model | Accuracy | Precision | Recall | F1-score |
| :--- | :---: | :---: | :---: | :---: |
| Model 1(SVM) | 0.78 | 0.77 | 0.78 | 0.77 |
| Model 2(Random Forest) | 0.85 | 0.86 | 0.85 | 0.85 |
| Model 3(XGBoost) | 0.91 | 0.91 | 0.92 | 0.91 |

### 성능 분석
* Model3(XGBoost)의 성능이 가장 우수했습니다.
* 이유 : sEMG 데이터는 5개의 다채널에서 수집되는 복잡하고 노이즈가 많은 비선형 시계열 신호입니다. 트리기반의 앙상블 기법을 사용하는 XGBoost 모델이 근육 활성화 패턴의 미세한 차이와 비선형적 관계를 가장 효과적으로 학습하여, 가장 높은 Accuracy와 F1-score를 나타냈습니다.





## 3. Confusion Matrix 분석
### Model 1 (SVM)
* 가장 잘 분류된 클래스 : Rest(휴식상태)
* 가장 많이 오분류된 클래스 : Fist(주먹쥐기)와 Grasp(움켜쥐기)
* 주요 오분류 유형 : 손에 힘을 주는 동작 간의 신호가 비슷하여 모델이 두 클래스를 혼동함
* 오분류 원인 분석 : 30°와 60° 각도 차이에서 오는 미세한 근육의 신호 변화를 선형 기반 분류기로는 완벽히 구분하기 어려웠음

### Model 2 (XGBoost)
* 가장 잘 분류된 클래스 : Fist, Finger Extension
* 가장 많이 오분류된 클래스 : 30°각도에서의 동작과 60°각도에서의 동일 동작
* 주요 오분류 유형 : 동일한 손동작이나, 팔꿈치 각도에 따라 일부 전완근의 활성도가 달라지는 것을 오인함
* 오분류 원인 분석 : 팔꿈치 각도가 변함에 따라 sEMG 신호의 진폭이 변하게 되는데, 일부 피험자의 경우 각도 변화에 따른 신호 차이가 크지 않아 분류기가 같은 각도로 오판하는 사례가 발생함





## 4. 최종 결과
* 가장 성능이 좋은 모델 : XGBoost(Accuracy 91%)
* 가장 성능이 낮은 모델 : SVM(Accuracy 78%)
* 주요 오분류 클래스 : 동작의 종류는 같으나 팔꿈치 각도(30° VS 60°)만 다른 클래스들 간의 혼동
* 전체적인 실험 결과 및 느낀 점: 제공된 코드를 통해 확인한 결과 sEMG 5채널의 파형은 동작이 일어나는 특정 구간에서 뚜렷한 특징이 보였습니다. 하지만 동일한 동작이라도 팔꿈치 각도(30°, 60°)에 따라 수집되는 생체 신호 파형이 상당히 다르다는 것을 확인할 수 있었습니다. 따라서 높은 정확도의 손동작 분류 모델을 만들기 위해서는 단순히 손동작 특징뿐만 아니라 상완근의 신호를 통해 팔꿈치 각도의 맥락을 함께 학습하는 과정이 중요함을 깨달았습니다.
